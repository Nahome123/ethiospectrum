Errorless Teaching & Intensive Teaching ስህተት-አልባ ማስተማር እና ጠንካራ ማስተማር

Nebraska ASD Network · Hopebridge Autism Therapy Centers ለኢትዮጵያውያን RBT ተሰልጣኞች የቀረበ ሁለት-ቋንቋ ስልጠና

What is Errorless Teaching?
ስህተት-አልባ ማስተማር ምንድነው?
An instructional method for teaching new skills and monitoring learned skills.
አዲስ ክህሎቶችን ለማስተማር እና የተማሩ ክህሎቶችን ለመከታተል የሚያገለግል የማስተማር ዘዴ ነው።
Involves using prompts that must be faded over time.
ከጊዜ ወደ ጊዜ ሊቀዘቅዙ የሚገባቸው ፍርዶችን (ፕሮምፕቶችን) መጠቀምን ያካትታል።
Why Use It? · ለምን እንጠቀምበት?
  • Used for individuals with learning difficulties and problem behaviorsየመማር ችግር እና ችግሮች ያሉባቸው ሰዎች ለማስተማር ያገለግላል
  • Faster acquisition of skillsክህሎቶችን በፍጥነት ለማዳበር ይረዳል
  • More opportunities to access reinforcementሽልማት ለማግኘት ብዙ አጋጣሚዎችን ይፈጥራል
  • Positive learning environmentአዎንታዊ የመማር ሁኔታን ያጠናክራል
  • Engaging — fast-paced and varied tasksፈጣን እና የተለያዩ ተግባሮች ስለሆኑ ተሳትፎን ያሳድጋሉ
What Skills Can Be Taught?
ምን ዓይነት ክህሎቶች ይማራሉ?
Almost any skill can be taught through errorless teaching!
ማለት ይቻላል ማንኛውም ክህሎት በዚህ ዘዴ ሊማር ይችላል!
  • Daily Living Skillsየዕለት ተዕለት ኑሮ ክህሎቶች
  • Verbal Behaviorየቃል ባህሪ
  • Fine Motor Skillsደቃቃ የሞተር ክህሎቶች
  • Motor Imitationየሞተር ኢሚቴሽን (ኮፒ ማድረግ)
Scientific Basis · ሳይንሳዊ መሠረት
  • Errorless teaching is an effective technique within Applied Behavior Analysis (ABA)ስህተት-አልባ ማስተማር በABA ማዕቀፍ ውስጥ ውጤታማ ዘዴ ነው
  • ABA is an evidence-based research practice for individuals with autism regardless of ageABA ለኦቲዝም ያለባቸው ሁሉ — በዕድሜ ሳይለይ — ሳይንሳዊ ማስረጃ ያለው ዘዴ ነው
  • Reducing errors reduces problem behavior and keeps learning positiveስህተቶችን መቀነስ ችግር ያለው ባህሪን ይቀንሳል እና ትምህርትን አዎንታዊ ያደርጋል
Two Types of Skills
ሁለት ዓይነት ክህሎቶች
"Known" Skills — Previously-mastered items the student can already do easily.
"የሚታወቁ" ክህሎቶች — ተማሪው አስቀድሞ ቀድሞ የተማራቸውና በቀላሉ ሊሰራቸው የሚችላቸው።
"Target" Skills — New skill items targeted for instruction (not yet mastered).
"ዒላማ" ክህሎቶች — ለትምህርት የተያዙ አዲስ ነገሮች (ገና ያልተማሯቸው)።
📊 80:20 Ratio — 80% known skills to 20% target skills (may vary by student)
80:20 ሬሾ — 80% የሚታወቁ ክህሎቶች እና 20% ዒላማ ክህሎቶች (በተማሪ ይለያያል)።
Lots of success minimizes frustration and builds behavioral momentum.
ብዙ ስኬት ስደሰት ስሜትን ይቀንሳል እና ትምህርታዊ ሞመንተምን (ፍጥነት) ያጠናክራል።
The 4-Step Teaching Procedure · 4 ደረጃ ያለው የማስተማር ሂደት
1
PROMPT
ፍርዱ (Prompt)
Give the least intrusive prompt that ensures a correct response
2
TRANSFER
ማስተላለፍ
Ask again WITHOUT the prompt — test independence
3
DISTRACT
ሌሎች ነገሮች
Do some easy "known" skills to "wipe the slate clean"
4
CHECK
ማረጋገጥ
Ask the target skill with NO prompting — assess true learning
1. PROMPT · ፍርዱ
  • Prompts are part of the antecedent condition (before the student behavior occurs)ፕሮምፕቶች ተማሪው ድርጊቱን ከማድረጉ በፊት ይሰጣሉ (ቅድምቱ ሁኔታ ነው)
  • Start with a prompted trial so the student gets the behavior correctተማሪው ትክክለኛ ምላሽ እንዲሰጥ ፍርዱ ካለ ሙከራ ጀምር
  • Choose the prompt that is least intrusive but still ensures a correct responseትክክለኛ ምላሽ የሚያረጋግጥ ነገር ግን ትንሹ ጣልቃ ገቢ ፕሮምፕት ምረጥ
  • You may need to do multiple prompt trials and fade slowlyብዙ ሙከራዎች ማድረግና ቀስ ብሎ ፕሮምፕቱን ማቀዝቀዝ ሊያስፈልግ ይችላል
2. TRANSFER · ማስተላለፍ
  • Prompts are faded through the use of a transfer trialፕሮምፕቶች በሽግግር ሙከራ አማካኝነት ቀስ ብለው ይቀዘቅዛሉ
  • Ask the same question again but without the promptያው ጥያቄ ፕሮምፕት ሳይኖር ደጋግሞ ጠይቅ
  • If student gives the desired behavior → move to distract trialsተማሪው ትክክለኛ ምላሽ ከሰጠ → ወደ "ሌሎች ነገሮች" ሂደት ሂድ
  • If student does NOT give the desired behavior → move to error correctionትክክለኛ ምላሽ ካልሰጠ → ወደ ስህተት ማረም ሂደት ሂድ
3. DISTRACT · ሌሎች ቀለል ያሉ ነገሮች
  • Place other responses between the prompt/transfer trials and the check trialከፕሮምፕት/ሽግግር ሙከራዎች እና የማረጋገጥ ሙከራ መካከል ሌሎች ምላሾችን አስቀምጥ
  • Think of it as "wiping the slate clean"ሰሌዳውን ጽድ ማድረግ አድርጎ ያስብ ("ሪሴት" ማድረግ)
  • Distracter trials come from "known" skills — things the student has already masteredየሌሎች ነገሮች ሙከራዎች ተማሪው ቀደም ሲል ካወቀው ክህሎቶች ነው
4. CHECK · ማረጋገጥ
  • Check trials assess whether the student can do the target skill after distractor trialsየማረጋገጫ ሙከራ ተማሪው ሌሎች ነገሮች ካደረጉ በኋላ ዒላማ ክህሎቱን ይችልかどうかን ይፈትሻል
  • There is NO prompting during the check trialበማረጋገጫ ሙከራ ወቅት ፕሮምፕት አይሰጥም
  • Correct responses indicate that the student is learningትክክለኛ ምላሽ ተማሪው እየተማረ ስለሆነ ያሳያል
  • Give the STRONGEST reinforcement after the check trial for independent performanceተማሪው ብቻውን ካደረገ በኋላ ለምልክቱ ትልቅ ሽልማት ስጥ
3 Types of Errors · 3 ዓይነት ስህተቶች
  • Incorrect — Wrong answer givenስህተት — ትክክል ያልሆነ ምላሽ ሲሰጥ
  • No response / too much time — Student doesn't answer within timeምንም ምላሽ/ዘግይቶ — ተማሪው ወቅቱ ሳይሆን ምላሽ ካልሰጠ
  • Scrolling — Student goes through multiple responses trying to find the right oneመስኮት ማሸብለል — ተማሪው ብዙ ምላሾችን እየሞከረ ትክክለኛውን ሲፈልግ
Error Correction Procedure · የስህተት ማረሚያ ሂደት
The error correction procedure is the same as the teaching procedure, but with an "End" step added at the beginning.
የስህተት ማረሚያ ሂደቱ ከማስተማሪያ ሂደቱ ጋር ተመሳሳይ ነው፤ ነገር ግን "ማቆሚያ" ደረጃ ይጨምርበታል።
End the trial wherever the student makes an error and go back to the beginning (the prompted trial) with a MORE intrusive prompt.
ተማሪው ስህተት ባደረገበት ቦታ ሙከራውን አቁምና ወደ መጀመሪያ ሂደት (ፍርዱ ሙከራ) ወደ ኋላ ሂድ — ነገር ግን ይበልጥ ጠንካራ ፕሮምፕት ይዘህ።

በማናቸውም ደረጃ ስህተት ከተፈጠረ → ፍርዱ (PROMPT) ከፊት END ጨምር እና ይበልጥ ጠንካራ ፕሮምፕት ተጠቀም።
Key Principle · ዋና መርህ
📌 Take probe data every day AND then errorlessly teach each target skill multiple times every day!
በየቀኑ ፍተሻ ዳታ አሰብስብ እናም ቀን ቀን ዒላማ ክህሎቶቹን ስህተት-አልባ ዘዴ ብዙ ጊዜ አስተምር!
First Things First · ቅድሚያ ሊሰጣቸው የሚገቡ ነገሮች
Pair Teaching with Improving Conditions! · ማስተማርን ከተሻሻሉ ሁኔታዎች ጋር አጣምር!
  • Pair instruction with positive reinforcementትምህርትን ከአዎንታዊ ሽልማት ጋር አጣምር
  • Fade in demands graduallyጥያቄዎችን ቀስ ብሎ ጨምር
  • Low response effort at firstመጀመሪያ ቀለል ያሉ ምላሾችን ጠይቅ
  • Immediate delivery of reinforcementሽልማቱን ወዲያውኑ ስጥ
  • Reduce learner errorsየተማሪው ስህተቶችን ቀንስ
  • Fast-paced instructionፈጣን ትምህርት
  • Intersperse easy and hard tasksቀለል ያሉ እና ከባድ ተግባሮችን ቀያይር
  • Teach to fluencyእስከ ቅልጥምነት ድረስ አስተምር
⭐ All of the above help reduce escape-based behavior!
ሁሉም ከላይ ያሉት ነገሮች ማምለጥ-ተኮር ባህሪን ለመቀነስ ይረዳሉ!

  • Use what you know about the student to create a motivating context for learningተማሪዉን ስለሚያነሳሳ ነገር ያለህን እውቀት ተጠቀምበት

ጥያቄ፡ ክህሎት በብዙ አካባቢዎች ሲሰለጠን ወደ ምን ሊደርስ ይችላል? | መልስ፡ ወደ ዕቅፍ (Generalization) - አጠቃላይነት ምንድነው?

RBT Training Glossary
የRBT ስልጠና መዝገበ ቃላት
ABC ሀ-ባ-ሐ (ABC)
Antecedent – Behavior – Consequence. Also known as the 3-term contingency.
ቀዳሚ ሁኔታ – ባህሪ – ውጤት። የ3-ቃል ሁኔታዊ ሰሌዳ ተብሎም ይታወቃል።
Behavior ባህሪ
Anything a person does that can be observed and measured. Has 4 functions: Automatic/Sensory, Escape, Attention, Access.
ሰው የሚያደርገው ሁሉ — ሊታይ እና ሊለካ የሚችለው። 4 ተግባራት አሉ፡ ሰራሽ/ስሜት፣ ማምለጥ፣ ትኩረት፣ ተደራሽ።
Discrete Trial (DTT) ቆራጥ ሙከራ (DTT)
A learning opportunity initiated and controlled by the teacher in which the correct response will be reinforced. Breaking a skill into smaller parts and teaching it with reinforcement.
አስተማሪው የሚቆጣጠረው ትምህርታዊ አጋጣሚ ሲሆን ትክክለኛ ምላሽ ሽልማት ያገኛል። ክህሎቱን ትንንሽ ክፍሎች ከፍሎ ሽልማት ይዘህ ማስተማር።
Extinction ዳሟ (Extinction)
The withholding of reinforcement for a previously reinforced behavior, resulting in reduction of that behavior.
ቀድሞ ሽልማት ለሚያገኝ ባህሪ ሽልማቱን ማቆም — ያ ባህሪ ቀስ ብሎ ይቀንሳል።
Extinction Burst የዳሟ ፍንዳታ
The increase in frequency and/or intensity of behavior in the early stages of extinction.
ዳሟ ሲጀምር ባህሪ ቅድሚያ ብዙ ወይም ጠንካራ ሆኖ ይጨምራል።
Generalization አጠቃላይነት (Generalization)
Change occurs when behavior happens outside of the learning environment — across settings, time, and people.
ያ ባህሪ ከትምህርት አካባቢ ውጭ — በሌሎች ቦታዎች፣ ጊዜ እና ሰዎች ጋር — ሲከሰት።
Mand ማንድ
A verbal operant — requests for a specific item or activity.
ቃላዊ ኦፐራንት — ለተወሰነ ዕቃ ወይም ድርጊት ጥያቄ።
Tact ታክት
A form of verbal behavior where the speaker sees, hears, smells, or tastes something and comments about it (a label).
ተናጋሪው ነገር ሲያይ፣ ሲሰማ ወይም ሲሸት ስሙን ወይም ነውን ሲናገር — ስም ሰጪ ቃላዊ ባህሪ።
Reinforcement ሽልማት (Reinforcement)
Positive: A stimulus presented after behavior that increases the behavior. Negative: A stimulus removed after behavior that increases the behavior.
አዎንታዊ፡ ባህሪ ካደረጉ በኋላ ሚጨምር ነገር ሲሰጥ። አሉታዊ፡ ባህሪ ካደረጉ በኋላ ደስ የማያሰኝ ነገር ሲወሰድ።
Shaping ቀረፃ (Shaping)
The process of reinforcing gradual changes in behavior so the behavior begins to look like the target behavior.
ባህሪ ቀስ ብሎ ወደ ዒላማ ባህሪ እንዲቀርብ ሽልማቱ ቀስ ብሎ ለሚቀርቡ ዓይነቶች ሲሰጥ።
Task Analysis ተግባር ትንተና
The process of breaking a skill down into smaller, more manageable components.
ክህሎት ወደ ትናንሽ፣ ሊተዳደሩ ወደሚችሉ ክፍሎች የሚከፋፈልበት ሂደት።
Chaining ሰንሰለት ማስተማር
Used to teach multi-step skills in which steps are defined through task analysis. Can be done backward, forward, or total task.
ብዙ ደረጃ ያላቸውን ክህሎቶች ለማስተማር ያገለግላል። ወደ ኋላ፣ ወደ ፊት ወይም ሙሉ ደረጃ ሊሆን ይችላል።
Intraverbal ውስጠ-ቃላዊ (Intraverbal)
Building blocks of conversation — the ability to discuss, describe, or answer a question about something not physically present.
የውይይት ግንባታ ድንጋዮች — አካላዊ ሳይኖር ስለ ነገሮች ለመወያየት ወይም ጥያቄ ለመመለስ ችሎታ።
Prompt ፍርዱ (Prompt)
Part of the antecedent condition (before behavior) that increases the likelihood of the correct response.
ከባህሪ በፊት ያለ ሁኔታ ሲሆን ትክክለኛ ምላሽ ለማምጣት ይጠቅማል።
Take-Away Points
ዋና ዋና መርሆዎች
✅ Errorless teaching can be used for a wide variety of skills
ስህተት-አልባ ማስተማር ለብዙ ዓይነት ክህሎቶች ሊያገለግል ይችላል
✅ Errorless teaching is appropriate at nearly any age
ስህተት-አልባ ማስተማር ለማንኛውም ዕድሜ ተስማሚ ነው
✅ Reducing errors reduces problem behavior and keeps learning positive
ስህተቶችን መቀነስ ችግሩ ያለ ባህሪን ይቀንሳል
✅ Prompt with the least intrusive prompt that still ensures a correct response
ትክክለኛ ምላሽ የሚያረጋግጥ ትንሽ ጣልቃ ገቢ ፕሮምፕት ተጠቀም
✅ Pick target skills that are appropriate and meaningful for each individual student
ለእያንዳንዱ ተማሪ ተስማሚ ዒላማ ክህሎቶች ምረጥ
✅ Normal: Prompt – Transfer – Distract – Check
መደበኛ ሂደት፡ ፍርዱ – ሽግግር – ሌሎች ነገሮች – ማረጋገጥ
✅ Error: End – Prompt – Transfer – Distract – Check
ስህተት ሲኖር፡ ማቆም – ፍርዱ – ሽግግር – ሌሎች ነገሮች – ማረጋገጥ
✅ Take probe data every day and errorlessly teach each target skill multiple times daily!
ፍተሻ ዳታ በየቀኑ ሰብስብ እና ዒላማ ክህሎቶቹን ስህተት-አልባ ዘዴ ብዙ ጊዜ አስተምር!
