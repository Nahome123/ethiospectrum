# Demo reconciliation (PRD v1.0, section 42 / Phase 6)

The PRD makes the existing demo the technical starting point but not a source of requirements. Every demo feature is classified below.

- **KEEP**: matches the PRD unchanged.
- **ADAPT**: kept, but changed to match the PRD.
- **RETIRE**: conflicts with the PRD or isn't part of it.
- **NEW**: built for the PRD.

Retired features stay in the codebase with their data intact. They are switched off by the constants in [`config/features.ts`](../config/features.ts). Their route segments render the not-found page and their API routes return 404 (`requireFeature` / `retiredApiResponse` in `lib/features.ts`). Their navigation links are removed and their GitHub Actions schedules are disabled. Re-enabling any of them is a product change request, not a configuration toggle. `tests/unit/retired-features.test.ts` guards every gate.
