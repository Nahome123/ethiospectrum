# IEP and 504 accommodations source provenance

The supplied bilingual HTML is archived unchanged at `docs/source-artifacts/iep-504-accommodations-original.html`. It contains 18 categories and 187 example accommodations in English and Amharic. The archive is a provenance record only: its external font links, inline styles, and inline reading-progress script are not loaded, fetched, framed, injected, or executed by Ethiospectrum.

The protected runtime guide at `/[locale]/member/resources/iep-504-accommodations` uses the extracted typed data in `features/resources/iep-accommodations/content.json`. React renders fixed headings, links, and semantic tables; a small local Client Component supplies only scroll progress and the back-to-top control. The guide makes no network request and stores no user progress or family data.

The supplied educational wording and Amharic translation are preserved without silent correction. Before public release, a qualified special-education reviewer should review accuracy and scope, a native Amharic reviewer should review the translation, and the project owner should confirm permission to publish the supplied material. The guide is a discussion aid, not a guarantee of IEP or Section 504 eligibility and not legal or educational advice.
